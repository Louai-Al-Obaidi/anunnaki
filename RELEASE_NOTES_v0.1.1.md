# Anunnaki v0.1.1

## Installation

**No Python installation is required.** Download `Anunnaki.exe` from the GitHub Release and run it. The portable executable bundles the Python runtime and required application dependencies.

## Changes

- Added explicit Windows taskbar and title-bar branding for the Anunnaki logo.
- Simplified the public download path to one self-contained Windows EXE.
- Clarified user-first installation guidance in the README.

## For developers

Developers can clone the source repository to inspect, modify, test, or rebuild the application. See the Developer section in the README.
