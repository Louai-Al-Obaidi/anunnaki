# Support

Anunnaki is an independent open-source project maintained by its community. It
is not a Microsoft product and does not include Microsoft support.

## Getting help

Search existing GitHub Issues before opening a new one. Use the issue templates
for reproducible bugs and feature requests. Include the app version, Windows
version, input format, and the exact error message where relevant; never attach
private documents or credentials.

## Security issues

Do not report vulnerabilities in a public issue. Follow the private reporting
instructions in [SECURITY.md](SECURITY.md).
